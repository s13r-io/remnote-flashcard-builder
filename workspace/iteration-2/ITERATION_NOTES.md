# Iteration 2: Refinements Based on Iteration 1 Analysis

## Changes Made to Skill

### 1. Improved Reverse Card Guidance
**Problem identified:** Some reverse cards were incorrectly formatted as forward cards
**Example:** Python "List >> Is mutable or immutable?" should be "Is mutable? << List"
**Fix:** Clarified in SKILL.md that Reverse (`<<`) is used when identifying/naming something FROM its property/characteristic

### 2. Strengthened Multiple-Choice Emphasis
**Problem identified:** WW2 (exam-prep focused) had 0 MC cards; Python had only 4
**Fix:** Added explicit guidance:
- Lean towards MC cards for content involving distinctions between options
- Use for exam-prep format practice
- Examples: "Which battle happened first?", "Which is immutable?", "Compare X vs Y"

### 3. Clarified Redundancy vs Atomicity Balance
**Problem identified:** Minor redundancy (e.g., nearly identical Q&A pairs)
**Fix:** Updated guidance to minimize TRUE redundancy while maintaining atomic extraction
- Different card FORMATS for the same fact = OK (variation in learning angle)
- Same card TYPE with nearly identical answers = minimize

### 4. Expanded Card Type Variety Expectations
**Guidance added:**
- Aim for 5-6+ different card types per document (was implied, now explicit)
- Multiple-Choice should be more prominent in exam-prep contexts

## Expected Improvements in Iteration 2

✅ More correct use of Reverse cards
✅ Higher Multiple-Choice card count (especially in WW2)
✅ Better exam-prep focus
✅ Reduced minor redundancy while keeping atomic coverage
