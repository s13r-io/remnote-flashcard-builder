## Limits

- **Limit (in calculus)** :: The value that a function approaches as the input approaches a given value
- **What does the notation lim(x→a) f(x) = L mean?** >> As x gets closer to a, f(x) gets closer to L
- **When does a limit exist?** >> Only if the left-hand limit and the right-hand limit are equal
- Limits are the foundation of both {{derivatives}} and integrals.
- **A function is continuous at a point if what condition holds?** >> The limit at that point equals the function's value there
- **Given: a function's limit at a point equals the function's value there** << Continuity at that point

## Derivatives

- **Derivative of a function** :: A measure of the function's instantaneous rate of change at a given point
- The derivative is defined as the limit of the {{difference quotient}}: f'(x) = lim(h→0) [f(x+h) - f(x)] / h.
- **What does the derivative at a point represent geometrically?** >> The slope of the tangent line to the curve at that point
- **Differentiation** :: The process of finding a derivative
- **List three common notations for the derivative** >>>
f'(x) (prime notation)
dy/dx (Leibniz notation)
Df (operator notation)
- **dy/dx** <> Leibniz notation for the derivative

## Basic Differentiation Rules

- **Power rule** :: The derivative of x^n is nx^(n-1)
- **Constant rule (differentiation)** :: The derivative of a constant is zero
- **Sum rule (differentiation)** :: The derivative of a sum equals the sum of the derivatives
- **Product rule** :: (fg)' = f'g + fg'
- **Chain rule** :: For composite functions, if y = f(g(x)), then dy/dx = f'(g(x)) · g'(x)
- **Quotient rule** :: (f/g)' = (f'g - fg') / g²
- **Which rule is used to differentiate composite functions?** >>A) Chain rule B) Product rule C) Quotient rule D) Sum rule
- **Describe: used when differentiating a product of two functions, result is f'g + fg'** << Product rule

## Applications of Derivatives

- **In physics, what is velocity?** >> The derivative of position with respect to time
- **In physics, what is acceleration?** >> The derivative of velocity with respect to time
- **Critical points** :: Points where f'(x) = 0 or f'(x) is undefined
- **First derivative test** ;; Determines whether a critical point is a local maximum, local minimum, or neither
- **Second derivative test** ;; Uses concavity to classify critical points
- **If f''(x) > 0 at a critical point, what does it indicate?** >> The function is concave up, so the point is a local minimum
- **If f''(x) < 0 at a critical point, what does it indicate?** >> The function is concave down, so the point is a local maximum
- **Concave up at a critical point indicates what type of extremum?** >>A) Local minimum B) Local maximum C) Inflection point D) Saddle point

## Integrals

- **Integration** :: The reverse process of differentiation
- **Indefinite integral** ;; Written as ∫f(x)dx, represents a family of functions differing by a constant C
- **Definite integral** ;; Written as ∫[a to b] f(x)dx, calculates the net area between the curve and the x-axis from x = a to x = b
- The indefinite integral is also called the {{antiderivative}}.
- **In a definite integral, are areas below the x-axis positive or negative?** >> Negative
- **In a definite integral, are areas above the x-axis positive or negative?** >> Positive

## The Fundamental Theorem of Calculus

- **Fundamental Theorem of Calculus** :: The theorem that connects differentiation and integration, showing they are inverse operations
- **Fundamental Theorem of Calculus, Part 1** ;; If F(x) = ∫[a to x] f(t)dt, then F'(x) = f(x)
- **Fundamental Theorem of Calculus, Part 2** ;; ∫[a to b] f(x)dx = F(b) - F(a), where F is any antiderivative of f
- **What practical method does the Fundamental Theorem provide?** >> A method for evaluating definite integrals using antiderivatives
- **Describe: F'(x) = f(x) where F(x) = ∫[a to x] f(t)dt** << Fundamental Theorem of Calculus, Part 1

## Common Integration Techniques

- **Power rule for integration** :: ∫x^n dx = x^(n+1)/(n+1) + C (for n ≠ -1)
- **U-substitution** ;; Reverses the chain rule by replacing a composite expression with a single variable
- **Integration by parts** ;; Reverses the product rule: ∫u dv = uv - ∫v du
- **Partial fractions** ;; Decomposes rational functions into simpler fractions that can be integrated individually
- **List four basic integration techniques** >>>
Power rule for integration
Substitution (u-substitution)
Integration by parts
Partial fractions
- **Which integration technique reverses the chain rule?** >>A) U-substitution B) Integration by parts C) Partial fractions D) Power rule
- **Which integration technique reverses the product rule?** >>A) Integration by parts B) U-substitution C) Partial fractions D) Power rule
